# divination-skills · 三味占卜技能包

给 AI 助手用的三套占卜技能包:**小六壬**(快卦)、**六爻**(纳甲深卦)、**塔罗**(意象心镜)。
每个包都是标准技能结构 —— `SKILL.md`(触发条件与工作流)+ `references/`(分册资料)+ `scripts/`(起卦/排盘/抽牌脚本)。

## 资料出处(重要)

- **小六壬 `xiaoliuren/`** —— 基于仓库主人早年自己学习、整理的资料与笔记编成。三宫配六神、宫位含义、体用与合宫的判法,出自她自己的学习脉络,不是网络汇编。
- **六爻 `liuyao/`** —— 由 Claude 检索公开资料后比对、整理、总结编写:纳甲装卦、世应六亲、旬空月破、旺衰与应期等,取通行的传统规则。
- **塔罗 `tarot/`** —— 同样由 Claude 检索公开资料整理:以 Rider-Waite-Smith 78 张牌体系为准,牌义、正逆位、牌阵位置义与解读法均为总结性编写。

一句话:小六壬那一份是人的学习成果,六爻和塔罗两份是 AI 的资料整理。取用前请自行判断。

## 技术要点

- 脚本只用 Python 标准库(小六壬/六爻另需 `cnlunar` 做农历与干支换算),**零网络请求、零写盘**,可离线运行。
- 确定性起法(报数、指定卦名、指定六爻、指定牌名)与随机起法(铜钱、摇骰、洗牌)分开实现,方便宿主系统落实「卦面即印章」——随机只在服务端摇,落定即锁,模型只负责断、不负责起。
- `tarot/scripts/draw.py` 的中文牌名匹配带别名兜底(高塔→塔、金币/钱币→星币、女教皇→女祭司等)。

## 怎么用

1. 支持技能包的环境(如 Claude Code):整个文件夹放进技能目录即可。
2. 自建系统:把 `scripts/` 收编成服务端工具,`SKILL.md` 里的起卦步骤改成调用你自己的工具,`references/` 做成按需翻阅的资料册。
